검정 방법과 판정 기준

번호·번호쌍·3개 조합의 최댓값은 가능한 전체 후보 중 최댓값과 비교합니다. 최솟값은 아래쪽, 고정 패턴 빈도는 기대값 양쪽을 비교합니다. 극값의 기대는 시뮬레이션 평균이며, 편차는 관측에서 기대를 뺀 값입니다.

경험적 p값은 (관측만큼 극단적인 반복 수 + 1) ÷ (반복 수 + 1)입니다. Holm 보정 후 기간 4개와 반복 횟수 2개도 보정합니다. 기본 시드 645에서 보정 p ≤ 0.05이면 유의한 편차, 보정 전 p ≤ 0.05이거나 95% 범위 밖이면 추가 검증으로 표시합니다. 사용자 시드는 탐색용입니다. 유의한 편차와 미래 예측력은 별개입니다.

비교 조건과 해석

개발은 1,000회까지, 평가는 1,001회부터로 고정했습니다. 추첨 직전 연속 50회가 있는 회차를 사용합니다. 같은 회차의 5번째 게임은 전 전략이 공유하며, 나머지 4게임을 전략별로 생성합니다. 무작위 5게임은 각각 균등하게 생성합니다.

빈출·저빈출 가중과 번호 분산은 조합 생성기의 규칙을 사용합니다. 장기 미출현은 마지막 등장 이후 회차 수 순서, 번호쌍은 동시 출현 횟수 순서로 선택합니다. 패턴 필터는 홀짝 3:3, 합계 100~149, 연속번호 1쌍 이상을 고정 적용합니다.

평균 일치의 95% 추정 구간은 회차 단위 블록 부트스트랩입니다. 보정 p는 당회차의 게임 간 번호 중복을 반영한 단측 순차 검정에 Holm 보정을 적용한 값입니다. 이 평가는 과거 재현입니다. 미래 성과는 추첨 전에 조합을 기록하고 별도로 확인해야 합니다.

모의 수익률은 해당 회차 게임 가격과 공시된 세전 1게임당 당첨금을 사용합니다. 5개 적중 등수는 보너스로 구분하며, 당첨금 자료가 빠진 경우 수익률을 표시하지 않습니다.

데이터 해석 및 한계

출처: 이 HTML 파일에 내장된 1150~1249회 데이터는 캐시로지의 동행복권 공개 자료 정리 페이지를 참고해 구성했습니다. 공식 원본 DB에 직접 연결된 서비스는 아닙니다. 구매 기록은 사용자가 이 브라우저에서 직접 등록합니다.

정확성: 결과 발표 전인 회차는 자동으로 당첨 판정하지 않습니다. 이력 업데이트 후 당첨 결과는 공식 동행복권에서 다시 확인하세요. 1~3등 당첨금이 데이터셋에 없으면 금액을 추정하지 않습니다.

통계: 각 회차의 추첨은 독립 시행입니다. 고빈도, 저빈도, 동반 출현, 홀짝, 번호 합계, 백테스트는 설명·연구용이며 미래 번호 예측 능력이 확인된 것은 아닙니다.

개인정보: 기본 대시보드는 외부 서버에 개인 구매 기록을 전송하지 않습니다. 온라인 갱신은 당첨 데이터 CSV를 요청하는 기능일 뿐입니다.
