# LOTTO LAB 5.2.2 긴급 수정: 45개 점수와 30개 순위 선정

PR #9의 [긴급 수정 요청](https://github.com/jlpjj84-cyber/lotto-ai-lab/pull/9#issuecomment-7064252518)을 반영한다. 기존 5.2.1은 일부 번호의 가중치를 올린 뒤 무작위 추출하고 5번째 게임을 무작위로 고정했다. 그 구조는 이번 점수 추천에 사용하지 않는다.

## 실제 동작

1. 1회부터 최신 확정 회차까지 본번호 6개만 시간순으로 읽는다. 보너스는 통계에 사용하지 않는다.
2. 시차별 전이, 동일 회차 번호쌍, 동일/혼합 간격 연쇄, 복합 조건을 관측 자료에서 자동 탐색한다. 이전과 같은 최소 표본/빔/메모리 예산을 사용하며 제한은 그대로 표시한다.
3. 현재 성립하는 **모든 등록 조건**으로 45개 번호 각각에 양·음의 편차를 계산한다. 상위 일부 번호만 평가하지 않는다.
4. 번호별 점수로 전체 순위를 만든 뒤 기본 5게임의 **30개 위치 전부**를 동일한 결정적 순위 알고리즘으로 선정한다. 다섯 번째 게임의 특별 처리나 무작위 채우기는 없다.
5. 선택 이전 45개 후보 점수·순위, 게임별 감점, 각 단계 남은 후보와 선택 번호, 실제 역사적 횟수·관련 조건·검증 상태를 저장한다.

## 점수 정의

조건 c의 과거 발생 수 N, 번호 n의 성공 수 S, 기준 p=6/45일 때 완화 편차는 `(S-N*p)/(N+20)`, 신뢰도 계수는 `N/(N+20)`이다. 전이/동일 회차 집합/시간 연쇄/혼합 집합 연쇄의 각 유형 안에서 신뢰도 가중 평균을 구한 뒤, 현재 존재하는 유형에 동일 비중을 주고 100을 곱한다. 음의 편차도 포함한다.

이 점수는 여러 겹치는 조건에서 관측된 편차의 연구 지수이며 다음 회차 당첨 확률이나 보정된 예측 확률이 아니다. 유형별 조건 수 차이로 한 유형이 압도하지 않도록 유형 평균을 사용한다. 번호별 대표 관계는 각 유형에서 최종 점수 기여 절댓값이 큰 1개씩이며, 나머지 조건의 기여 합계도 별도로 기록한다. 대표 관계만으로 점수를 계산했다고 설명하지 않는다.

표본이 충분한 조건이 없으면 45개 모두 0점으로 표시하고 **근거 부족**을 명시한다. 유효한 전체 자료에 대한 0점 실험은 아래 동점 규칙으로 선정하며 근거를 지어내지 않는다. 데이터가 불완전하거나 분석 자체가 실패하면 점수 추천을 중단하고, 사용자가 별도 무작위 대조군을 볼 수 있게 한다. 실패한 분석을 정상 추천으로 포장하지 않는다.

## 6개 선정과 분산

- 최초 게임: 분석 점수 내림차순의 상위 6개.
- 다음 게임: `선정 점수 = 분석 점수 - (45개 점수 범위 × 0.35 × 이전 게임 사용 횟수)`.
- 동점: 이전 사용 횟수가 적은 번호 → 원래 분석 점수가 높은 번호 → 번호 오름차순.
- 같은 게임에서는 이미 선택한 번호를 제외하고 6개를 순서대로 결정한다. 게임 안의 각 선택은 같은 게임 시작 점수표를 참조한다.
- 동일 조합 제외 옵션은 이미 나온 상위 조합을 건너뛰고 순위 인덱스 조합의 사전식 다음 후보를 고른다. 분산 옵션은 이전 게임 사용 번호를 명시적으로 제외한다. 두 제약은 기록에 포함하며 기본 평가와 직접 비교하지 않는다.
- 점수 추천 함수 `chain-ranking.js`는 외부 모듈이나 난수기를 가져오지 않는다. 시드는 점수 추천 결과를 바꾸지 않으며 대조군과 불확실성 계산에만 사용한다.

`chain-control.js`의 무작위 생성은 대조군에만 쓰인다. 기본 대조군은 기존 균등 무작위 전략 5게임과 같다. 화면과 수동 생성에는 **분석 점수 실험 추천 / 별도 균등 무작위 대조군** 선택이 있고 번호와 설명을 섞지 않는다.

## 실제 검증과 제한

1~1251회 전체로 1252회 추천을 생성했다. 현재 900개 조건을 원자료에서 다시 세어 45개 점수를 독립 산식으로 대조했다. 5게임 30개 위치의 감점·남은 후보·순위·대표 조건·실제 성공 횟수도 별도 구현으로 일치 여부를 검사했다. 과거 251개 평가 회차 전부도 당시의 직전 자료 상태에서 같은 순위를 독립 재현했다.

평가 기간은 1001~1251회, 각 5게임/1255게임이다. 실험 평균 적중 0.812749, 무작위 0.799203, 차이 +0.013546, 회차 블록 10의 95% 근사 차이 구간 −0.035857~0.061355, 순차 조건부 검정 p=1이다. **예측 우위는 확인되지 않았다.** 3개 적중은 32 대 27게임, 4개는 0 대 1게임이며 5·6개는 양쪽 0이다. 기능 요구 충족과 실제 예측력 입증을 구분한다.

기존 9개 전략·구매 저장·사전 확정 번호/해시/영수증/평가를 변경하지 않는다. 이전 5.2.1 자동 스냅샷과 수동 기록도 변경하지 않고 읽기 호환을 유지하며, 화면에 이전 가중 무작위 기록임을 표시한다. 선택적 초기 5.2 과거 연구 재현도 현재 점수 추천과 명확히 구분한다.

분석 후보는 관측/표본/빔 예산 내의 탐색이며 모든 45의 거듭제곱 패턴을 완전 탐색하지 않는다. 자동 연구와 사용자 생성 기록은 기존 9개 사전 확정 실전 집계에 포함하지 않는다. 점수식과 분산 계수는 이번 평가 결과에 맞춰 사후 최적화하지 않았다. 실험 추천에는 통계적으로 검증된 예측 우위가 있다는 표시를 하지 않는다.
